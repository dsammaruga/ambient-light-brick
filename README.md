# Ambient Light brick

Sample brick for Arduino App Lab, used to test the App Bricks registry submission flow.

- `bricks/ambient_light/`: the brick (`__init__.py`, `brick_config.yaml`, `README.md`)
- `examples/basic/`: an App Lab app using it

Each tag is a submittable version: the archive GitHub generates for the tag, or the asset attached to the release, holds this repository tree.
